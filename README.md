# L_lang
Linguagem de programação feita inteiramente em C++ (Ainda em Desenvolvimento).
Algumas partes podem estar vazias, ainda estou programando ela.
Ela foi construida usando o DeepSeek.
Essa linguagem foi pensada para ser Fácil, é de baixo nivel, utilizando a Syntax dá Linguagem Lua, com algumas modificações.
ela por enquanto só funciona no Linux, Apenas utilize ./l para usar.
Ainda estou pensando em Portar essa Linguagem parar o Android, é Futuramente para o Windows.
